## 一、单选题（每题 2 分）

### [Q:gesp-l1-single-01] C++ 算术运算符与整除
执行以下 C++ 代码后，变量 `result` 的输出值是（ ）。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 14;
    int b = 4;
    int result = a / b + a % b;
    cout << result << endl;
    return 0;
}
```

- [x] A. 5
- [ ] B. 5.5
- [ ] C. 6
- [ ] D. 7

**【教师基础解析】**:
在 C++ 中，两个整型（int）相除执行的是整除运算，直接舍去小数部分。14 / 4 的商为 3；14 % 4 为求余数运算，结果为 2。因此 result = 3 + 2 = 5。选项 A 正确。

**【考纲知识点】**: `算术运算（除法与求余）`、`整型变量与整除特性`
**【讲解动画】**: `/videos/gesp-l1-single-01.mp4`

## 二、判断题（每题 2 分）

### [Q:gesp-l1-judge-01] C++ 标识符命名规则判断
在 C++ 语言中，变量名可以使用字母、数字和下划线组成，因此 `2024_score` 是一个合法的 C++ 变量名。

```cpp
int 2024_score = 100;
```

- [ ] 正确 (T)
- [x] 错误 (F)

**【教师基础解析】**:
C++ 标识符只能由英文字母、数字和下划线组成，且必须以字母或下划线开头，绝对不能以数字开头。`2024_score` 以数字开头是非法的。

**【考纲知识点】**: `程序基本概念（标识符命名规则）`

## 三、编程题（每题 25 分）

### [Q:gesp-l1-coding-01] 小明的苹果采购
- **时间限制**: 1.0 秒
- **内存限制**: 128.0 MB

#### 题目描述
小明去超市买苹果，每个苹果单价 5 元。若购买数量达到或超过 10 个，总价打 9 折（乘以 0.9）；打折后若非整数，向下取整保留整数。输入苹果数 $n$（$1 \le n \le 100$），输出最终应支付金额。

#### 输入格式
输入一行一个正整数 $n$。

#### 输出格式
输出一行一个整数表示最终金额。

#### 样例 1
**输入**:
```
8
```
**输出**:
```
40
```

#### 样例 2
**输入**:
```
11
```
**输出**:
```
49
```

#### 官方标准满分代码（C++11，一级考纲内）
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;
    int total = n * 5;
    if (n >= 10) {
        total = int(total * 0.9);
    }
    cout << total << endl;
    return 0;
}
```
